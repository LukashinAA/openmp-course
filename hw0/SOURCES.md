# Источники и инструменты

## Источники и инструменты

Материалы первого семинара OpenMP: условие ДЗ0 и шаблон `templates/student-repo` из пакета `openmp-s01-posle`. При подготовке использовался помощник Codex, терминал macOS, GCC 16.2.0 и Git.

## Для чего

Из шаблона взяты исходники hello/pi, Makefile, скрипты замеров, графиков и CI. Codex помог подготовить репозиторий, проверить сборку, собрать паспорт стенда, исправить обнаружение GCC, выполнить замеры, построить графики и оформить отчёт. Предварительный прогноз предложен помощником и согласован студентом до замеров, затем сохранён отдельным коммитом `5468d44`.

## Где источник ошибся

Поиск Homebrew GCC в `common.mk` и `tools/sysinfo.sh` проверял только версии 15, 14, 13, 12. На этой машине установлен GCC 16, поэтому автоматический выбор переходил к Apple clang без установленного libomp. В список поиска добавлен GCC 16. В автоматически собранном паспорте указано одно значение L1d для всех ядер; оно уточнено раздельно для P- и E-ядер по sysctl.

## Как проверяли

Выполнены `make -C hw0 info all test`: выбран gcc-16, программы собираются, вычисление pi проходит проверку на 1, 2 и 4 потоках. Проверены версии компилятора и макрос `_OPENMP=202111`. Локальный `make tsan` завершился ошибкой отсутствия omp.h у Apple clang; на Linux в GitHub Actions проверка Clang 18 + Archer на 2 и 4 потоках прошла. Выполнены 30 измерений pi на своём Mac после прогрева, все ответы проверены с допуском 1e-9; CSV использован для таблицы и трёх графиков. Разницу RESULT порядка 1e-12 между разными числами потоков не скрывали, она разобрана в отчёте.
