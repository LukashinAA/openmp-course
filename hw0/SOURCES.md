# Источники и инструменты

## Источники и инструменты

Материалы курса `openmp-s01-posle`, GCC 16.2.0, Git и помощник Codex.

## Для чего

Код hello/pi и скрипты взяты из шаблона курса. Codex использовался для настройки,
замеров, графиков и оформления; прогноз согласован студентом до замеров.

## Где источник ошибся

Шаблон искал GCC только до версии 15, на компьютере установлен GCC 16.
Версия 16 добавлена в поиск в `common.mk` и `tools/sysinfo.sh`.

## Как проверяли

`make test` прошёл на 1, 2, 4 потоках, ThreadSanitizer — в GitHub Actions на Linux.
Все 30 результатов замеров совпали с pi с допуском 1e-9.

## Что сделано самостоятельно

Студент указал вариант, выбрал публичный репозиторий, выполнил вход в GitHub
и согласовал прогноз. Настройка и оформление выполнены с помощью Codex,
вычислительные исходники курса не изменялись.
